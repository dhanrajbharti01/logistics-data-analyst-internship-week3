# Logistics Data Analyst Internship - Week 3

## Advanced Data Analysis and Visualization in Python

This repository contains my Week 3 work for the Logistics Data Analyst Internship.

### 📌 Project Overview

The objective of this task is to perform advanced data analysis and visualization on logistics delivery data using Python. The analysis focuses on delivery performance, traffic impact, distance, planned vs actual delivery time, and operational efficiency.

### 📊 Dataset

The dataset contains logistics order information with the following variables:

- Order ID
- Distance (km)
- Parcel Count
- Traffic Level
- Hour
- Vehicle Capacity
- Planned Time (min)
- Actual Time (min)

### 🔍 Analysis Performed

- Dataset structure and exploratory data analysis (EDA)
- Descriptive statistics
- Mean and median analysis
- Correlation analysis
- Traffic-level delivery performance analysis
- Distance vs actual delivery time analysis
- Delivery time distribution analysis
- Correlation heatmap
- Identification of operational bottlenecks
- Logistics efficiency insights and recommendations

### 📈 Visualizations

The project includes:

1. Average Delivery Time by Traffic Level
2. Distance vs Actual Delivery Time
3. Distribution of Actual Delivery Time
4. Correlation Heatmap

### 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter/VS Code
- GitHub

### 📂 Files Included

- `logistics_orders.csv` – Dataset
- `week3_logistics_analysis.py` – Python analysis code
- `Week_3_Advanced_Data_Analysis_and_Visualization_Logistics_Report.docx` – Detailed project report

### 💡 Key Insights

The analysis shows that traffic conditions and delivery distance have a noticeable impact on actual delivery time. The correlation analysis also highlights the relationship between planned delivery time, distance, parcel count, and actual delivery performance.
